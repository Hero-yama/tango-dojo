# 準1級 単語道場(PWA版)

スマホのホーム画面に置いて、アプリのように使える版です。

## 中身

- `index.html` … アプリ本体
- `manifest.webmanifest` … アプリ名・アイコンの設定
- `sw.js` … オフラインでも開けるようにする仕組み
- `icons/` … ホーム画面用アイコン

この4つを**フォルダ構成のまま**ネット上に置けば完成です。

## 収録語彙

- 組み込み803語(優先度「高」350語・「中」241語・「低」212語)。優先度が高い語から順に出題されます。
- 自分で追加できるのは最大197語(合計1,000語まで)。単語帳の「語彙の追加」から登録します。
- 組み込み語を増やす・直すときは、`index.html` 内の `EXTRA` の行(英語|品詞|意味|例文|優先度)を編集します。

## 公開する方法

### いちばん簡単:Netlify Drop(1分)

1. パソコンで https://app.netlify.com/drop を開く
2. このフォルダ(`tango-dojo-pwa`)をまるごと画面にドラッグ&ドロップ
3. 表示された `https://〜.netlify.app` がアプリのURL
4. 無料アカウントを作って「Claim」しておくと、URLが消えずに残ります

### 長く使うなら:GitHub Pages(無料)

1. https://github.com でアカウントを作る
2. 右上の「+」→「New repository」。名前は `tango-dojo`、**Public** を選んで作成
3. 「uploading an existing file」を押し、このフォルダの中身(`index.html`、`manifest.webmanifest`、`sw.js`、`icons` フォルダ)をドラッグして「Commit changes」
4. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」
5. 数分後、`https://ユーザー名.github.io/tango-dojo/` で開けます

## スマホに入れる

- **iPhone**:Safariで上のURLを開く → 共有ボタン →「ホーム画面に追加」
- **Android**:Chromeで開く → メニュー →「アプリをインストール」(または「ホーム画面に追加」)

一度開けば、圏外でも使えます。

## 注意

- 学習記録はその端末の中に保存されます。アプリ(ホーム画面のアイコン)を削除すると記録も消えます。
- 記録はブラウザ版とホーム画面版で別々です。使うときは毎回ホーム画面のアイコンから開いてください。
- アプリを直したときは、`sw.js` の1行目近くにある `tango-dojo-v3` を `v4` のように1つ上げてからアップロードし直すと、スマホ側も新しい版に切り替わります。
- 設定画面の「書き出す」で学習記録をJSONファイルに保存できます。端末を変えるときは「読み込む」で引き継げます。
